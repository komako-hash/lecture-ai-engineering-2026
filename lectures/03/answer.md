# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
  第1回の素のLLMは講座専用の用語集を参照する機能がないため、講座固有の内容について正確に答えられるとは限らない。一方、第3回のエージェントは用語集を検索するツールを使用できる。「3レベル」について質問したところ、3つのレベルから1つ選べば宿題が完了することを説明し、最後に関係する回を表示した。ただし、3つのレベルの名称は明示されなかった。

- `--trace` で見えたツール呼び出し（ツール名と引数）：
  「LoRAとQLoRAの違いは？」という質問に対し、`search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})` が呼び出された。また、「第2回の内容から確認問題を1問出して」という質問では、`make_quiz({'lecture': 2})` が呼び出された。

- 1つの質問でのLLM呼び出し回数（`requests`）：
  「LoRAとQLoRAの違いは？」では `requests=2`、`tool_calls=2` だった。また、「第2回の内容から確認問題を1問出して」では `requests=2`、`tool_calls=1` だった。

- 追加したツールと、docstringに書いた説明：
  `make_quiz(lecture: int) -> str` を追加した。指定した講義回の用語集からランダムに用語を1つ選び、確認問題と答えを生成するツールである。docstringには「指定した講義回の用語から確認問題と答えを作る。復習用の問題を求められたときに使う」と記述し、実行時にツールが呼び出されることを確認した。

## 宿題

- 取り組んだレベル：基礎

- やったこと：
  `app/agent.py` の `INSTRUCTIONS` にある「回答の最後に、関係する回（第N回）を示す」という指示を、「回答の最後に、学習内容を確認するための確認問題を1問出す」に変更した。変更前後で同じ「LoRAとQLoRAの違いは？」という質問を `--trace` 付きで実行し、回答内容とツールの呼び出し回数を比較した。

- 結果：
  変更前は `search_glossary` が2回呼び出され、`requests=2`、`tool_calls=2` だった。回答の最後には「関係する回：第2回」と表示された。

  変更後は `search_glossary` が2回呼び出されたことに加え、`make_quiz({'lecture': 2})` が1回呼び出された。`requests=3`、`tool_calls=3` となり、回答の最後に「教師ありファインチューニング（SFT）」についての確認問題が出題された。

- 気づき・疑問：
  AIへの指示を1か所変更するだけで、回答の形式だけでなく、使用するツールやLLMの呼び出し回数まで変化することが分かった。特に、確認問題を出すように指示しただけで、エージェントが自動的に `make_quiz` を利用した点が興味深かった。一方、ツールの呼び出しが増えることで処理時間やAPIの利用コストも増加するため、必要なツールを適切に使わせる指示設計が重要だと感じた。
